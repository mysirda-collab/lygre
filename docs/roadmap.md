# Roadmapa projektu Lygre

## Fáze 0 — Příprava a návrh
- dokončení architektonického návrhu,
- definice datových modelů,
- vytvoření základní struktury repozitáře,
- schválení rozsahu a priorit.

## Fáze 1 — Základní infrastruktura
- inicializace backendu a frontendu,
- nastavení Docker Compose,
- databázové migrace,
- základní autentizace a API skeleton.

## Fáze 2 — Core workflow
- správa zákazníků,
- zakázky,
- základní workflow stavů.

## Fáze 3 — Plánování a komunikace
- rezervace termínů,
- plánování techniků,
- SMS integrace.

## Fáze 4 — Admin a reporting
- administrace uživatelů a rolí,
- reporty a exporty,
- optimalizace výkonu a bezpečnosti.

## Fáze 5 — Stabilizace a nasazení
- testování,
- dokumentace pro provoz,
- nasazení do produkčního prostředí.
